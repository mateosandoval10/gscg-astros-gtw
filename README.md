# Group Ticket Website (GSCG concept)

A framework group-ticket site built from a shared Google Doc.
- Content edits in the doc show on the site within about 30 seconds (apps-script/Code.gs serves the doc).
- "Request:" lines sent from the doc's Website menu run Claude Code on GitHub Actions (.github/workflows/site-request.yml), which edits the site and reports back to the doc.
Rules for the AI live in CLAUDE.md. GSCG concept for Houston Astros Group Sales; not an official Astros page.
