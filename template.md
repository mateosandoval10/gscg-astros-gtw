How this doc works: this doc IS the group ticket website. Website: https://mateosandoval10.github.io/gscg-astros-gtw/
1. Write like a normal Google Doc. Each Heading 1 is a part of the website, each Heading 2 is one item inside it (a tier, an experience, a seating area, a question).
2. Short facts like "From: To confirm" or "Good for: Large school groups" show up as labeled details. Everything else is normal text.
3. Edits show on the website within about 30 seconds. Refresh the website to see them.
4. To ask the AI for anything bigger (new pages, pop-ups, design changes), write it under Requests at the bottom. Start with "Request:" and end with your name in parentheses, like (Daphne). It can be several paragraphs.
5. The request changes to Working, then Done with a note. You can delete it once it says Done. Do not edit it while it says Working.
6. Unconfirmed info always says "To confirm". Put "Owner: Your name" and "Status: Idea, Draft, Needs info or Ready" under your headings.
